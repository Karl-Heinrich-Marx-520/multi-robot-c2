# 设备参考资料

完整资料随仓库公开保存在 [设备资料 Release](https://github.com/Karl-Heinrich-Marx-520/multi-robot-c2/releases/tag/device-materials-20261119) 的 **Assets** 中，可直接下载；克隆代码不会下载这些附件。

| 附件 | 约大小 | 内容与用途 |
|---|---|---|
| `protocols-and-reference-source.zip` | 9.7 MiB | 6 份协议 PDF、已提取的 top_akm_dl ROS 功能包、Go2 接口笔记及头文件。接入开发建议先下载这一份。 |
| `noetic_src_20241022.zip` | 1.03 GiB | 原始完整 Noetic 源码包，用于查找导航等其他 ROS 功能包。 |
| `r680-vendor-materials.zip` | 1.51 GiB | R680 厂商硬件说明、故障排查、开发手册、STM32 源码包、芯片与原理图、下载工具和教程视频。 |

资料快照日期为 2026-11-19，共 370 个原始文件。[catalog.csv](catalog.csv) 按原目录列出每个文件的路径和字节数；两个新增 ZIP 保留原有目录，Noetic ZIP 为原文件。附件均小于 GitHub 单个 Release 文件的 2 GiB 限制。

协议和 SDK 笔记用于查阅，适配前仍需核对实机型号、固件与权限。第三方源码、工具和文档沿用各自原有授权；仓库未给这些资料重新授予许可。
