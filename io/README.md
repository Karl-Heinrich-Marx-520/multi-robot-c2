# 通信层：丞翰

`api/ilink.hpp` 定义调度使用的 IO 边界：发送返回本地入队状态，订阅统一接收消息与通信事实，统计暂无样本时返回空值。订阅句柄销毁即退订。

`mock/` 为单线程、手动驱动的测试替身：`take_sent()` 观察发出的请求，`inject()` 注入回执、终态、链路中断或超时事实。消息可以重复注入或选择不注入以模拟不同输入；计时、丢包、重连和截止后的队列处理需测试驱动显式控制。mock 不自动生成成功回执，不是 UDP 模拟设备。

后续在 `src/` 实现编解码、UDP、队列、投递截止、重试、去重、心跳和会话恢复；当前 mock 仅在 send 调用时检查本地截止，不承诺完整 IO 行为。公共类型与接口修改需要子延及受影响设备负责人审阅。
