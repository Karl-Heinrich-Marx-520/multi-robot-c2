### 1.1 下发帧

| 字节索引 | 定义 |
|---|---|
| 0 | 0x7B |
| 1–2 | 预留，当前写 0x00 |
| 3–4 | vx × 1000，有符号 16 位，大端；vx 单位 m/s |
| 5–6 | vy × 1000，有符号 16 位，大端；vy 单位 m/s |
| 7–8 | 偏航角速度 × 1000，有符号 16 位，大端；单位 rad/s |
| 9 | 字节 0–8 的 XOR |
| 10 | 0x7D |

编码时浮点数转换为 short，会向零截断；当前这段代码没有限幅。编码范围不是车辆安全工作范围，实际指令应遵守车型能力与限速。阿克曼车不能因帧中存在 vy 字段就推断支持横移。

### 1.2 反馈帧

证据：`src/wheeltec_robot.cpp:325–407`，换算常数见 `include/wheeltec_robot.h:38–47`。成对数值均高字节在前，按有符号 16 位解析。

| 字节索引 | 定义与换算 |
|---|---|
| 0 | 0x7B |
| 1 | Flag_Stop / 预留，当前解析后未见后续使用，不能直接当作任务停止确认 |
| 2–3 | vx_raw / 1000，m/s |
| 4–5 | vy_raw / 1000，m/s；注释说明仅全向底盘有效 |
| 6–7 | 偏航角速度 raw / 1000，rad/s |
| 8–9、10–11、12–13 | IMU ax、ay、az：raw / 1671.84，m/s² |
| 14–15、16–17、18–19 | IMU gx、gy、gz：raw × 0.00026644，rad/s |
| 20–21 | 电压 raw / 1000，V |
| 22 | 字节 0–21 的 XOR |
| 23 | 0x7D |

反馈不含 task_id、任务受理 ACK 或导航完成 RESULT，因此统一任务协议必须由设备 agent 实现。控制板内部如何从 vx 与偏航角速度计算转向角，当前所查 ROS 源码没有提供；不能把标准单车模型公式标成已验证的固件实现。反馈频率 50 Hz 仍需运行或固件配置验证。
