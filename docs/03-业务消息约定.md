## 追加方式

确定一项业务约定后，按消息类型找到对应章节，将模板复制到该章节末尾并填写。每条约定标明设备、业务名称、消息方向和字段类型；不要重复公共协议内容。

### 参考示例：四驱车 · GUIDE

以下只展示填写格式，具体业务以双方确认结果为准。

方向：中控 → 四驱车

| 字段 | JSON 类型 | 必填 | 单位 / 取值 | 含义 |
|---|---|---|---|---|
| `action` | `string` | 是 | `GUIDE` | 引导小车到目标位置 |
| `params.channel` | `string` | 是 | 待约定 | 目标通道 |
| `params.target` | `string` | 是 | 待约定 | 目标位置 |
| `params.speed_mps` | `number` | 是 | m/s，范围待约定 | 引导速度 |

行为约定：小车收到后校验参数，能够执行则返回接受 ACK，执行结束后返回 RESULT；具体受理、完成、失败和取消条件待双方确认。

## 追加模板

```markdown
### [设备] · [业务名称]

方向：[发送方] → [接收方]

| 字段 | JSON 类型 | 必填 | 单位 / 取值 | 含义 |
|---|---|---|---|---|
| `[字段路径]` | `[string/number/boolean/object/array/null]` | [是/否] | [约定] | [说明] |

行为约定：[触发、处理、完成或失败条件]
```
