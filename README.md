# 多机器人中控

面向四驱车 top_akm_dl、无人机与宇树 Go2 X 的统一中控。第一版目标是在单机 4 个进程中验证“机器狗上报堵塞 → 中控并行派出观察与引导任务 → 收到回执和结果”，并覆盖丢包、重复、乱序及断线恢复。

目前仅完成背景与接口文档整理，尚无代码和运行验证。

- [项目背景与交接](docs/00-项目背景与交接.md)：目标、分工、架构、进度与待补事实。
- [接口协议 v0.2](docs/01-接口协议.md)：统一消息、时钟、回执、去重、取消与会话恢复。
- [设备资料核查](docs/02-设备资料核查.md)：四驱车源码证据、Go2 接口证据与无人机资料缺口。

无人机暂按 UDP 接入考虑，上层协议尚未确认；模拟器拟使用 JSON over UDP。文档约定仍需团队评审与设备能力确认。
